# SS10 — IEEE Research Paper

## Project structure

- `main.tex` — IEEE conference document entry point.
- `sections/01_introduction.tex` — Introduction, research gap, research questions and contributions.
- `sections/02_methodology.tex` — Methodology, mathematical formulation, system architecture and experimental parameters.
- `references.bib` — Zotero / Better BibTeX bibliography with 11 references.
- `figures/` — diagrams and figures used in the paper.

## How to compile

1. Open the project in Overleaf.
2. Set `main.tex` as the Main document.
3. Compile using pdfLaTeX and BibTeX.
4. Check citations, references, equations, tables and figures in the generated PDF.
